<p align="center">Distribuição Linux para inferência de IA local, parte do ecossistema Lyra.</p>

O Neuryx é uma edição do [Lyra OS Server](https://github.com/lyra-os-linux/lyraos-server)
voltada à execução de modelos de IA locais com GPUs NVIDIA e
[llama.cpp](https://github.com/ggml-org/llama.cpp). O projeto está no início:
as decisões de arquitetura e as pesquisas em andamento ficam no repositório
[`research`](https://github.com/neuryx-os/research).

## Ecossistema Lyra

O Neuryx usa os pacotes e a base do Lyra OS, mantidos na organização
[`lyra-os-linux`](https://github.com/lyra-os-linux).

Para contribuir, leia o [guia de contribuição](https://github.com/neuryx-os/.github/blob/main/CONTRIBUTING.md).
