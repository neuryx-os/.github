# Política de segurança

## Como reportar uma vulnerabilidade

**Não abra issue pública** para relatar vulnerabilidades.

Envie um e-mail para **rodrigo@w3ti.com.br** com:

- o repositório e a versão ou commit afetados;
- a descrição do problema e o impacto esperado;
- os passos para reproduzir, se possível;
- se quiser, como prefere ser creditado.

Confirmaremos o recebimento e manteremos você informado sobre a correção. Pedimos
que a vulnerabilidade não seja divulgada antes de haver correção disponível ou
de combinarmos uma data.

## Escopo

Esta política cobre todos os repositórios da organização `neuryx-os`.
Problemas em componentes de terceiros — como o llama.cpp, o driver NVIDIA ou
pacotes herdados do Lyra OS e do openSUSE — devem ser reportados também ao
projeto de origem. Para pacotes do Lyra OS, veja a organização
[`lyra-os-linux`](https://github.com/lyra-os-linux).
