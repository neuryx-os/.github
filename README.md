# .github

Perfil da organização e arquivos de comunidade compartilhados do Neuryx.

**Status:** Em desenvolvimento

## Propósito

O GitHub usa este repositório para:

- exibir `profile/README.md` na página da organização
  [`neuryx-os`](https://github.com/neuryx-os);
- aplicar `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, o template
  de pull request e os templates de issue a todos os repositórios da
  organização que não tenham os próprios.

## Estrutura

```
.github/
├── profile/README.md          # página da organização
├── CONTRIBUTING.md            # fluxo de contribuição e commits
├── CODE_OF_CONDUCT.md         # Contributor Covenant 2.1 (pt-BR)
├── SECURITY.md                # como reportar vulnerabilidades
├── PULL_REQUEST_TEMPLATE.md
└── ISSUE_TEMPLATE/            # bug, melhoria, pesquisa
```

## Relação com outros repositórios

- [`research`](https://github.com/neuryx-os/research): ADRs citados no guia de contribuição.
- [`brand`](https://github.com/neuryx-os/brand): logo exibido no perfil.
